# Структура документов

## Инструкция

Инструкция состоит из названия, результата, предварительных условий, последовательности действий и проверки результата. Один шаг описывает одно основное действие. Для зависимых действий используйте нумерованный список, для независимых условий — маркированный.

## Справочная страница

Справочная страница определяет сущность, её поля, допустимые значения и ограничения. Не смешивайте справку со сценарием выполнения задачи: дайте на инструкцию отдельную ссылку.

## Описание API

Для каждой операции укажите назначение, HTTP-метод, путь, способ аутентификации, параметры, тело запроса, возможные ответы и ошибки. Пример запроса должен соответствовать примеру ответа.

## Инструкция разработчика

Укажите версию необходимых инструментов, переменные окружения, команды запуска, способ проверки и частые ошибки. Перед командой, которая изменяет или удаляет данные, добавьте предупреждение и безопасный вариант, если он доступен.

## Заголовки

На странице используйте один заголовок первого уровня. Не пропускайте уровни заголовков и называйте раздел по его содержанию: «Настройка PostgreSQL» понятнее, чем «Дополнительно».
