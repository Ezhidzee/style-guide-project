# Глоссарий

| Сущность | Использовать | Не использовать без необходимости |
| --- | --- | --- |
| Booking | бронирование | заказ, заявка |
| Restaurant | ресторан | заведение |
| Guest | гость | посетитель, клиент |
| Table | столик | место |
| Booking status | статус бронирования | состояние заказа |
| Confirmation | подтверждение бронирования | акцепт |
| Cancellation | отмена бронирования | аннулирование |
| Application Programming Interface | API | программный интерфейс |
| Uniform Resource Locator | URL | веб-адрес |

Используйте «бронирование» для записи гостя на столик в определённое время. Если в продукте появится оплата, не называйте бронирование «заказом», пока эти сущности не будут описаны отдельно.
