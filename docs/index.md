# Руководство по стилю документации

Это руководство устанавливает правила для документации сервиса бронирования ресторанов. Оно помогает единообразно описывать пользовательские действия, REST API, конфигурацию сервисов и действия при сбоях.

## Для кого предназначено руководство

Авторы документации — разработчики, технические писатели и инженеры сопровождения. Читатели — пользователи сервиса, интеграторы и участники команды разработки. Перед публикацией автор выбирает тип документа и применяет правила из соответствующего раздела.

## Основные договорённости

- Документ отвечает на одну задачу читателя.
- Факты, команды и примеры проверяются до публикации.
- Одна сущность имеет одно название во всех документах.
- Изменение продукта сопровождается проверкой связанных страниц.
