# Как создать бронирование через API

Этот учебный пример показывает структуру инструкции для интегратора, который создаёт бронирование через REST API. Перед началом получите тестовый токен доступа и идентификатор ресторана.

## Отправьте запрос

```bash
curl --request POST 'https://api.example.test/api/v1/bookings' \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "restaurant_id": "rest_123",
    "guests": 2,
    "starts_at": "2026-10-16T19:00:00+03:00"
  }'
```

## Проверьте ответ

При успешном создании API возвращает статус `201 Created` и идентификатор бронирования:

```json
{
  "id": "booking_456",
  "status": "pending_confirmation"
}
```

Если на выбранное время нет свободного столика, API возвращает ошибку доступности. Измените время, количество гостей или выберите другой ресторан, затем повторите запрос.
