# Как запустить сервис локально

Эта учебная инструкция показывает, как оформлять запуск сервиса бронирования в среде разработки. Она предназначена для разработчика с установленными Git, Docker и Docker Compose.

## Предварительные условия

- Установлены Docker Engine и Docker Compose.
- У вас есть копия репозитория сервиса.
- В файле `.env` указаны локальные значения переменных окружения без рабочих секретов.

## Запуск

1. Откройте терминал в корне репозитория.
2. Запустите сервисы:

   ```powershell
   docker compose up --build
   ```

3. Дождитесь сообщения о готовности API.
4. Откройте документацию API по адресу `http://localhost:8080/docs`.

## Проверка результата

В документации API должен быть доступен запрос проверки состояния сервиса. Если контейнер завершился с ошибкой, просмотрите его логи командой `docker compose logs <service_name>` и проверьте значения в `.env`.
